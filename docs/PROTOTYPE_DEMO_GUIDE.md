# Prototype Demonstration Guide

1. Start the server and open `http://localhost:3000`.
2. Create a fictional account using `.example` or `.test` contact details.
3. Sign in and confirm that the dashboard loads.
4. Add a fictional study record and refresh the page.
5. Open the challenges section and complete a challenge.
6. Demonstrate logout and verify that the session no longer grants access.
7. Open PDF extraction and upload a non-sensitive local PDF.
8. Review privacy, terms, and cookie notice pages.
9. Explain the AI approval gates: core application features work without an API key, while student-data AI requests remain blocked until approval is documented.
