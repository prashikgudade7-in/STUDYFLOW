# Files Included

- `server.js`, `package.json`, and `package-lock.json`: application entry point and dependencies.
- `config/`, `controllers/`, `middleware/`, `routes/`, `services/`, and `utils/`: backend implementation.
- `public/`: frontend source and required static assets.
- `tests/`: Node test suite.
- `docs/`: architecture, privacy, security, database, and demonstration documentation.
- `.env.example`: sanitized variable template.
- `.gitignore`: repository exclusion rules.
- `README.md`: evaluator setup and feature information.
