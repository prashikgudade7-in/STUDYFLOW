# Project Overview

## Problem statement

Students need a focused place to manage study records, track challenges, review progress, and receive a limited set of study-management assistance.

## Proposed solution

StudyFlow is a local web prototype built with a vanilla JavaScript frontend and a Node.js/Express backend. It uses SQLite for local persistence and provides account, session, study-record, challenge, notification, PDF-text, privacy, and optional AI-assistant workflows.

## Objectives

- Provide account-based access to a personal study dashboard.
- Persist study records and challenge attempts locally.
- Enforce secure password and session handling.
- Protect personal data through origin checks, authorization, and account-data controls.
- Keep optional AI provider integration separate from core local functionality.
- Provide clear setup instructions for a challenge demonstration.

## Target users

Students and evaluators demonstrating or reviewing the prototype locally.
